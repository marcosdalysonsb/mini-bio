# 🪪 Mini Bio — Marcos Dalyson

Ciência da Computação • Desenvolvimento Mobile • React Native

---

## 📌 Sobre o Projeto

Este projeto consiste em um **Card de Perfil (Mini Bio)** desenvolvido em **React Native**, criado para apresentar minha formação, status acadêmico e objetivos profissionais de forma moderna, limpa e responsiva.

---

## 🎯 Objetivos

- Criar uma apresentação pessoal moderna e minimalista;
- Destacar formação acadêmica e busca por estágio;
- Praticar estilização avançada com Flexbox e sombras no React Native;
- Desenvolver um componente responsivo para dispositivos móveis.

---

## 🛠️ Tecnologias

| Tecnologia | Utilização |
| :--- | :--- |
| **React Native** | Framework de desenvolvimento mobile |
| **TypeScript (TSX)** | Tipagem estática e lógica |
| **StyleSheet** | Estilização nativa e efeitos de brilho |
| **Expo** | Plataforma e ambiente de desenvolvimento |

---

## ⚙️ Funcionalidades

- 👤 **Foto de perfil com destaques visuais** e borda iluminada.
- 🎓 **Badges com informações acadêmicas** (Curso e Período).
- 📜 **Mini biografia resumida e objetiva**.
- 🎨 **Design escuro moderno (Dark Mode)** com efeito de brilho e profundidade.
